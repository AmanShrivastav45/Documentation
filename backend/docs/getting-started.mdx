# Getting Started

Welcome to the docs platform. This guide walks you through installing and
running the project locally.

## Installation

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env` and fill in your API keys.
4. Start the dev server with `npm run dev`.

<Callout type="warning">
  **Breaking change:** as of v2.0, the `/search` endpoint has been renamed to
  `/query`. Update any existing integrations accordingly.
</Callout>

## Next Steps

Once the dev server is running, open `http://localhost:5173` and pick a page
from the sidebar to continue exploring.
